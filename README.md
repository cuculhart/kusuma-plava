# Kusuma Plava（クスマ・プラヴァ）

日本の小説家・教科書制作者のための縦書き執筆エディタ。
左ペインで横書きに書くと、右の版面が縦書きの原稿用紙として
レンダリングされていく。
v1.0.0 からデスクトップアプリ（Electron）として配布。

> 木漏れ日と花筏。文を書けば、組版が流れ出す。

変更履歴は [CHANGELOG](CHANGELOG.md) を参照。

## 機能

- **執筆モード** — 横書きの執筆ペインと原稿用紙の2ペイン構成。
  Enter で段落頭の字下げ（全角1字）、＊/◇の話区切り挿入、
  選択範囲の B/I/U と書式解除
- **原稿用紙** — ページ中央に配置される升目枠。既定は
  縦20字×横20行（400字詰）。「升目 縦N字×横N行」を文書設定で
  変更でき、字サイズは升目から自動決定される。線の色と透過も
  変更可
- **ルビ** — `｜親字《ヨミ》`（範囲明示）と `親字《ヨミ》`
  （直前の漢字連続、なろう式）。入力糖衣 `親字(-ヨミ-)` と
  `[-親字-] (-ヨミ-)` も受理
- **半角** — 短い連続は縦中横、長い連続は1字1マスの回転表示
- **禁則** — 行頭禁則（句読点・中点・感嘆疑問・閉じ括弧・
  長音繰返し・小さい仮名ほか）と行末禁則（開き括弧）を
  実務ルール準拠で処理
- **文字数** — 総字数・選択範囲・400字換算枚数。目標字数と
  進捗バー。ステータスバーに版面の升目（縦×横）を常時表示
- **自動保存** — 1.5秒デバウンスで IndexedDB に完全な文書状態
  を保存。起動時に下書きを復元
- **検索・置換** — Ctrl+F で検索バー、次/前・1件/全置換
- **青空文庫読込** — `.txt` 直接読込に加えて **青空 ZIP 書庫**
  （txt＋同梱画像）をそのまま読み込める。`［＃…入る］` 画像注記
  は空枠を生成して参照画像を自動充填し、注記の位置へ
  「次の段から画像＋次の段から本文再開」で配置（収まらなければ
  改ページ）。傍点はルビ欄の「・」、先頭の凡例ブロックは除外
- **画像差し込み** — 「画」メニューや貼り付けで版面へ画像を
  配置（ドロップで最上段/最下段へ吸着）。移動・縮尺・縦横比
  ロック解除・数値指定に対応し、注記形式で連鎖テキストへ記録
- **テキスト出力** — なろう・カクヨム提出用のプレーンテキスト
  （糖衣は `｜《》` に正規化、UTF-8 BOM）
- **用紙** — A4横が既定（A3/B5/B6/A5・縦横変更可）。ページ番号
  （ノンブル・下中央）、升目の印刷出し分け、用紙透過
- **フォント** — 既定は Noto Serif JP。推奨プリセット
  （明朝・ゴシック・教科書体・丸ゴシック）＋カスタム名の
  自由入力。1字1マスはフォントのメトリクスに依存しない実装
- **テーマ** — 標準（OS連動）/ 白 / 黒 / 静（紙調の執筆テーマ）
- **組版モード** — レイアウト編集（テキスト連鎖・画像・
  シェイプ・整列）へ切替可能
- **.chkpf 書庫** — zip 形式（doc.json＋画像バイナリ）の独自
  アーカイブ。画像の位置・回り込みも保存される。完全ローカル
  で外部送信なし（旧 `.slm` も開けます）
- **デスクトップ統合** — OS の「開く/保存」ダイアログで
  `.chkpf` を直接読み書きし、Ctrl+S で上書き保存。
  `.chkpf` を exe やウィンドウへドロップして開くこともできる。
  未保存のまま閉じる時は保存確認を表示。タイトルバーに
  文書名・ファイル名・未保存印 * を表示（ブラウザ版では従来
  どおりダウンロード/ファイル選択で読み書き）

## 使い方（デスクトップ版）

[Releases](https://github.com/cuculhart/kusuma-plava/releases)
から各 OS 向けの配布物を取得してインストール。

| OS | 配布形式 |
|---|---|
| Windows | `-win-x64.zip`（ポータブル — 解凍して `kusuma-plava.exe` を実行） |
| Linux | `.deb` |

## 使い方（開発・ブラウザ版）

```bash
git clone https://github.com/cuculhart/kusuma-plava.git
cd kusuma-plava
npm install
npm run dev       # http://localhost:5173
npm run build     # 本番ビルド → app/dist/
npm run typecheck
npm test
```

## 使い方（開発・デスクトップ版）

`desktop/` は Electron シェルの独立 npm プロジェクト
（root の `npm install` とは別に依存を持つ）。

```bash
cd kusuma-plava/desktop
npm install            # 初回のみ（electron バイナリをDL）
cd ..
npm run dev:desktop        # Vite dev + Electron で起動
npm run package:desktop    # out/ へ unpack 版を出力（ポータブル版）
npm run make:desktop       # インストーラ作成（Windows=Squirrel / Linux=deb）
                           # ※配布のポータブル版 zip は package 出力の
                           #   out/ を手動で圧縮する
```

## ルビ記法

| 入力 | 効果 |
|---|---|
| `漢字《かんじ》` | 直前の漢字連続にルビ |
| `｜少年的な謎の生き物《フラクトギャルソン》` | 範囲を明示したルビ |
| `運命(-さだめ-)` | 糖衣 → `運命《さだめ》` に正規化 |
| `[-未来-] (-みらい-)` | 糖衣の範囲明示形 |

## 技術構成

React + TypeScript + Vite + Electron。
組版は [inimbal](inimbal/)（純粋モデルの文字送り層 — 縦版 fit() は
単位カウントで、計測と描画が同じトークナイザを共有）、
描画エンジンに kimetron（`kimetron/` に vendored 同梱）、
書庫 zip に fflate。
デスクトップシェルは [desktop/](desktop/)（Electron +
electron-forge — Vite が束ねた `app/dist` を同梱する薄い殻で、
レンダラのコードはブラウザ版と共通）。
